# RestaurantMenuBot

Telegram-бот для ресторанного меню с франшизой, филиалами, категориями и блюдами.

## Что умеет

- Первичный владелец назначается прямо в боте через кнопку, без редактирования кода.
- Владелец может создавать одноразовые ссылки для младших администраторов.
- Администраторы редактируют франшизу, филиалы, категории и блюда.
- Обычные пользователи открывают меню кнопками, выбирают филиал, категорию и блюдо.
- Меню можно копировать из одного филиала в другой или сразу во все филиалы.
- Входящие сообщения пользователей автоматически удаляются.
- Бот старается редактировать одно своё сообщение вместо отправки новых.
- Фото блюд хранятся на сервере: локально для разработки или в MinIO на сервере.
- Прогресс заполнения админом сохраняется в базе и переживает перезапуск.
- В мастере заполнения есть кнопка «Назад»: можно вернуться к прошлому шагу, не теряя уже введённые данные.

## Команды

Команды админа намеренно не показываются пользователю в списке команд Telegram.

Полезные команды:

```text
/start
/menu
/admin
/help
```

## Первый запуск

1. Создайте бота через BotFather.
2. Скопируйте токен.
3. Создайте `.env` на основе `.env.example`.
4. Укажите `BOT_TOKEN`.
5. Запустите бота.
6. Откройте бота в Telegram и нажмите «Стать владельцем».

После назначения владельца повторно назначить владельца через первичную настройку нельзя.

## Хранение фото

По умолчанию используется локальное хранение:

```env
STORAGE_BACKEND=local
STORAGE_LOCAL_DIR=data/photos
```

Для сервера лучше использовать MinIO:

```env
STORAGE_BACKEND=minio
MINIO_ENDPOINT=minio:9000
MINIO_ACCESS_KEY=restaurant-menu
MINIO_SECRET_KEY=change-this-password
MINIO_BUCKET=dish-photos
MINIO_SECURE=false
```

Когда админ отправляет фото блюда, бот скачивает файл из Telegram и сохраняет его в серверное хранилище. В базе хранится только ключ объекта, а не сам файл.

Старые записи с `file_id` Telegram продолжают работать для совместимости.

## Защита от перезапуска

Черновики заполнения хранятся в таблице `admin_sessions` в SQLite.

Если админ начал добавлять блюдо, ввёл часть данных, а сервер перезапустился, бот после запуска предложит:

```text
Продолжить заполнение
Начать заново
```

При продолжении бот вернёт админа на тот же шаг.

Для автоматического подъёма после сбоя используйте Docker Compose:

```bash
docker compose up -d --build
```

В `docker-compose.yml` включено:

```yaml
restart: unless-stopped
```

Постоянные данные хранятся в томах:

- `./data` для SQLite и локальных фото
- `minio_data` для MinIO

## Основной сценарий администратора

```text
/admin
→ создать франшизу
→ создать филиал
→ добавить категорию
→ добавить блюдо
```

При добавлении блюда бот спрашивает:

1. Название
2. Описание
3. Цена
4. Вес или объём
5. Фото

На каждом шаге можно нажать «Назад» и изменить предыдущее значение.

## Редактирование блюд

Администратор может редактировать блюда внутри конкретного филиала:

```text
/admin
→ франшиза
→ филиал
→ категории
→ категория
→ блюдо
```

В карточке блюда доступны действия:

- изменить название
- изменить описание
- изменить цену
- изменить вес или объём
- изменить фото
- скрыть или снова показать блюдо в публичном меню

Редактирование не переносится на другие филиалы автоматически. Если нужно повторить меню, используйте копирование меню из одного филиала в другой.

## Кнопка «Пропустить»

На необязательных шагах больше не нужно писать слово вручную. Бот показывает кнопку «Пропустить» для описания, адреса, телефона, цены, веса и фото.

## Обновления v9

### Предпросмотр блюда перед сохранением

На последнем шаге добавления блюда бот показывает карточку так, как она будет выглядеть для гостя. Администратор может сохранить блюдо или нажать «Назад», чтобы вернуться к предыдущему шагу и исправить данные.

### Сохранённые значения при возврате назад

Если администратор возвращается на прошлый шаг заполнения, бот показывает уже сохранённое значение. Это помогает быстро понять, что было введено раньше.

### Быстрый возврат в главное админское меню

В админских разделах и мастере заполнения добавлена кнопка «В главное меню». Она возвращает владельца или администратора в главный экран админки без многократного нажатия «Назад».

### Публичный просмотр меню

В разделе категории названия блюд больше не дублируются в тексте сообщения. Они отображаются только в кнопках. Если блюд много, бот показывает их постранично.
